Project Name: Joki Coding Dumai - Official Website & Simple CMS
Target Audience: Clients needing web development, students, and local businesses in Dumai.
Tech Stack:

Frontend: Next.js (App Router), Tailwind CSS v4, Framer Motion (for lightweight, modern animations), Lucide React (icons).

Backend & DB: Next.js Route Handlers / Server Actions, Prisma ORM, MySQL.

SEO & Analytics: Next.js Metadata API, dynamic sitemap.xml, robots.txt, Google Search Console ready.

Core Features:

Public Facing Website (SEO Optimized):

Hero Section: High-converting landing area with rich, modern animations.

Services/Packages: Grid displaying available services and pricing tiers.

Portfolio: Showcase of past projects with images and tech stack tags.

Promos/Content: A blog-like section for updates, articles, or current discounts.

Order System: A dynamic form for clients to order websites. (Integration ready for automated WhatsApp notification).

Admin CMS (Protected Route):

Simple dashboard to manage (CRUD): Portfolio items, Packages, Promo content, and view incoming Orders.

Design & UX Guidelines:

Visuals: Modern, clean, tech-focused (matching the dark blue/purple/teal brand colors of the logo).

Animations: Smooth reveal on scroll, hover effects on cards, non-blocking animations to ensure fast First Contentful Paint (FCP).

Performance: High Lighthouse score, optimized images (next/image), mobile-first responsive design.
